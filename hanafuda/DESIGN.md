# はなふだ こいこい（CPU対戦）設計メモ

スマホ縦画面で遊ぶ、1人用（あなた vs CPU）の花札「こいこい」。
ビルド不要・外部ライブラリなし。`hanafuda/index.html` を開くだけで動く。

## ファイル構成

| ファイル | 役割 | DOM依存 |
| --- | --- | --- |
| `js/engine.js` | 札データ・役判定・得点・ゲーム進行（状態機械） | なし（Nodeでテスト可） |
| `js/ai.js` | CPUの思考（出す札・取る札・こいこい判断） | なし（Nodeでテスト可） |
| `js/art.js` | 札の絵柄をSVGで生成（各月の「かわいい子」） | 文字列を返すだけ |
| `js/ui.js` | 画面描画・タップ操作・演出・進行制御 | あり |
| `css/style.css` | スマホ前提のレイアウト（vw基準、100dvh） | - |
| `test/*.test.js` | `node --test` 用のユニット/シミュレーションテスト | - |
| `test/e2e.js` | Playwright でスマホ画面を実際に操作する確認 | - |

## ルール（ベーシック）

- 札：48枚（12か月×4枚）。光5・タネ9・短冊10・カス24。
- 配り：手札8枚ずつ、場8枚。場に同じ月が4枚そろったら配り直し。
- 手番：手札を1枚出す → 山札を1枚めくる。それぞれ同じ月の札が場にあれば取る。
  - 場に同じ月が1枚：その札を取る
  - 2枚：どちらか1枚を選んで取る
  - 3枚：3枚まとめて取る
  - 0枚：場に置く
- 役ができたら「こいこい（続ける）」か「勝負（あがる）」を選ぶ。
  - こいこい後は、役の点数がさらに増えたときに再度選べる。
  - 手札が残っていない場合は自動で勝負。
- あがった人が役の合計点を得る。**7点以上なら2倍**。
- 両者の手札がなくなっても誰もあがらなければ流局（0点、親はそのまま）。
- 勝った人が次の月の親（先手）。指定の月数（3/6/12）が終わったら合計点で勝敗。

### 役

| 役 | 条件 | 点 |
| --- | --- | --- |
| 五光 | 光5枚 | 10 |
| 四光 | 柳以外の光4枚 | 8 |
| 雨四光 | 柳を含む光4枚 | 7 |
| 三光 | 柳以外の光3枚 | 5 |
| 花見で一杯 | 桜に幕＋菊に盃 | 5 |
| 月見で一杯 | 芒に月＋菊に盃 | 5 |
| 猪鹿蝶 | 萩に猪＋紅葉に鹿＋牡丹に蝶 | 5 |
| 赤短 | 松・梅・桜の短冊 | 5 |
| 青短 | 牡丹・菊・紅葉の短冊 | 5 |
| タネ | タネ5枚（以降1枚ごと+1） | 1〜 |
| タン | 短冊5枚（以降1枚ごと+1） | 1〜 |
| カス | カス10枚（以降1枚ごと+1） | 1〜 |

役は重複して加算（例：赤短＋タン5枚 = 6点）。光系は最上位の1つだけ。

## 状態機械（engine）

```
startRound → phase 'play'（手番の人が手札を出す）
  playFromHand(cardId, targetId?) → 'draw'
  revealDraw()                    → 'drawn'（めくった札を表示）
  resolveDraw(targetId?)          → 役が増えた？ yes → 'koikoi' / no → 次の手番 'play'
  declare('koikoi' | 'stop')      → 'play'（相手番） or 'roundOver'
  （両者手札0）                    → 'roundOver'（流局）
nextRound() → 'play' or 'gameOver'
```

2枚から選ぶ必要があるのに targetId がない場合は `{ok:false, need:'target', options}` を返す。
UI と CPU は同じ API を呼ぶので、ルールのズレが起きない。

## CPU（ai.js）

- 見えている情報（自分の手札・場・双方の取り札）だけで判断（ズルなし）。
- 出す札：取れる札の価値（光＞タネ/短冊＞カス、役に近いほど加点、相手の役を邪魔する分も加点）、
  役が完成すれば大きく加点。取れない場合は「相手に取られても痛くない札」を捨てる。
- こいこい：7点以上・手札が少ない・相手が役に近い → 勝負。点が低く安全なら こいこい。
- 難易度「やさしい」は取れる札をランダムに選び、こいこいもざっくり判断。

## 画面（スマホ縦）

```
┌ CPU 点数 / 月 / メニュー ┐
│ CPUの手札（裏）           │
│ CPUの取り札（光/タネ/短/カス）│
│ 山札 ｜ 場の札             │
│ あなたの取り札             │
│ ヒント表示                 │
│ あなたの手札（8枚）        │
└ あなたの点数 ─────────┘
```

- 札の幅は `min(11vw, 58px)`、縦横比 1:1.6。375px幅で手札8枚が1列に収まる。
- 手札をタップ → 同じ月の場札が光る → もう一度タップ（または光った札をタップ）で出す。
- 取り札エリアをタップすると、取った札と今の役を大きく表示。

## テスト

- `node --test hanafuda/test/` … 札構成、役判定、取り方、得点計算、
  こいこい判定、AI vs AI の大量シミュレーション（札の総数が常に48枚など不変条件）。
- `node hanafuda/test/e2e.js` … Playwright で iPhone サイズの画面を開き、
  実際にタップして1局以上遊び、はみ出し・コンソールエラーがないか確認、スクリーンショット保存。
