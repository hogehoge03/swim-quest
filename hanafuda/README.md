# はなふだ こいこい 🌸

スマホで遊べる、CPU（はなちゃん）対戦の花札「こいこい」です。
札の絵柄は各月ごとのかわいい女の子・動物・花の妖精をSVGで描いています。

## あそぶ

`hanafuda/index.html` をブラウザで開くだけ（ビルド・サーバー不要、外部ライブラリなし）。
GitHub Pages で公開した場合は `https://<ユーザー名>.github.io/<リポジトリ>/hanafuda/` で遊べます。

- 手札をタップ → 同じ月の場札が光る → もう一度タップ（または光る札をタップ）で出す
- 取り札エリアをタップすると、取った札と今の役を大きく確認できます
- ルール・役一覧はタイトルの「あそびかた・役」から

## テスト

```sh
cd hanafuda
npm test        # ルール・役判定・AI同士の大量対戦シミュレーション（Node 18+）
npm run e2e     # Playwright でスマホ画面を実際に操作して通しプレイ（要 playwright）
```

設計の詳細は [DESIGN.md](DESIGN.md)。
